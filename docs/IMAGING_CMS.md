# Imaging CMS

Open `/admin/imaging` as active staff.

1. Create a bilingual draft study and first series.
2. Select modality, body region, orientation, classification, and linked structures.
3. Record source, license, attribution, and educational-use permission.
4. Confirm de-identification.
5. Upload a bounded web-ready frame batch or use an approved generated visual.
6. Add normalized annotations and references.
7. Submit, review, approve, and publish through database-enforced status rules.

The dashboard reports modality coverage and incomplete provenance. `review_due_at` supports scheduled scientific review. Imaging versions preserve published study metadata. Editors cannot publish directly, and anonymous users cannot read drafts.

The current point editor is intentionally small. Rectangle and polygon geometry are supported by the database contract and validation for later editor UI expansion.
